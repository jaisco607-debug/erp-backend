Software Safety Check

Textile ERP back-end system  |  Date: 21 October 2026  |  A plain-language summary for owners and managers
The short answer: the money and stock calculations at the heart of the system are sound. We tried to break them with thousands of automatic tests and they stayed correct to the last paisa. We did find a number of smaller weak spots. All but one have now been fixed and re-tested.

1. Why we did this

Before the system is handed over, we checked the whole thing the way an inspector would: is the costing right, can cloth go missing, can one company see another company's data, can the system be tricked or crashed, and is the database healthy?

4. What still needs a decision or an action

Decision for the owner: should Folding be limited to roughly what it received (for example, allow up to 5% gain or loss)? Today there is no limit. We left it as it is until you decide.

Action: one database update (indexes and safety rules) has been tested but not yet applied to your live database. It is quick and safe, and should be done with a backup in place.

Server settings: before going live, make sure the secret keys are long and random, and the system runs behind a normal web server. This is a setup task, not a software fault.

5. What this check did not cover

  • The screens and website (front end) were not part of this check.
  • Tests ran on a copy of the database engine on one computer; only read-only checks were run on your live database.
  • Speed was tested up to about 1,000 jobs. Much larger volumes should be re-checked later.
  • Business rules, such as how much loss is acceptable, are your decisions, not the software's.

6. Conclusion

The core of the system, which counts money and cloth, is reliable. The weak spots found were mostly places where the system allowed something a careful person would not do. Those have been closed and are now protected by automatic tests, so they cannot quietly return. Once the one open decision is made and the database update is applied, the system is in good shape to hand over.

Test result: 182 automatic tests, 181 passed, 1 skipped on purpose (speed test), 0 failed.

Textile ERP: APIs ki guide

Front end ke liye | Steps 1, 2a, 2b | 10 October 2026 | Har jawab asal API chala kar liya gaya he

1. Shuru karne se pehle (sirf 3 baaten)

a) Base URL: har API ke aage yeh lagta he: http://SERVER-ADDRESS:3000/api
Maslan login ka poora URL: http://192.168.1.10:3000/api/v1/auth/login. Asal address backend wala dega.

b) Har request ke header:
Content-Type: application/json (jab Body bhejni ho)
Authorization: Bearer ACCESS-TOKEN (login ke baad har API men; sirf jahan "Token nahi chahiye" likha ho wahan nahi)

c) CORS: aapka front end jis address par chalta he (maslan http://localhost:5173) woh backend wale ko bata den, woh use allow karega. Warna browser "CORS error" dega.

2. Login ka poora tareeqa (sab se zaroori)

KaunLogin screen par kya likhega
Super adminSuper admins ka code (sab super admins ka ek hi, maslan R4TW-9KXE) + Email + Password
Company ka admin (client admin) aur us ke usersCompany code (maslan K7QM-4XPA) + Email + Password

Login screen par 3 khane rakhen: Company code (zaroori, sab ke liye), Email, Password. Login ka jawab batata he:

  • user.userType: kaun sa dashboard kholna he. SUPER_ADMIN = super admin dashboard, CLIENT_ADMIN = company admin dashboard, USER = user dashboard.
  • company: kis company ka he (super admin ke liye null).
  • services: menu men sirf yahi dikhayen. access = FULL (add/edit kar sakta he) ya VIEW (sirf dekh aur report).

Token ka khel (simple)

  1. Login par 2 token milte hen: accessToken (lamba, 15 minute chalta he) aur refreshToken (chhota, 7 din). Dono save karen (maslan localStorage).
  2. Har API ke saath header: Authorization: Bearer accessToken
  3. Kisi API se 401 aaye: /v1/auth/refresh ko refreshToken bhejen. Naya accessToken aur naya refreshToken dono save karen (purana refreshToken ab band he). Phir wahi API dobara chalayen.
  4. Refresh bhi 401 de: tokens mita kar login screen par bhej den.
  5. Refresh ek waqt men sirf ek dafa chalayen. Ek purana refreshToken do dafa gaya to server security ke liye us user ke sab login khatam kar deta he.
  6. App khulte waqt GET /v1/auth/me chalayen: is se user, company aur menu (services) dobara mil jate hen.

3. Errors (sab ek hi shakal men aate hen)

{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Validation failed",
    "details": [
      {
        "field": "body.email",
        "message": "email must be a valid email"
      },
      {
        "field": "body.password",
        "message": "password is not allowed to be empty"
      }
    ]
  }
}
StatusMatlabFront end kya kare
400Form ka data ghalatdetails[].field batata he kaun sa khana (body.email = email). Wahan message dikhayen.
401Login nahi / token khatam / ghalat passwordRefresh karen (upar step 3), warna login screen.
403Is user ko ijazat nahiWoh screen/button chhupa den.
404Record nahi mila"Nahi mila" dikhayen.
409Pehle se mojood (maslan email)message dikhayen.
422Qaide ke khilaf (maslan band service kisi company ko dena)message dikhayen.
429Bohat zyada koshishen"15 minute baad koshish karen".
500Server ki ghalti"Kuch ghalat ho gaya" + requestId dikhayen.

Body men sirf woh fields bhejen jo is guide men likhi hen. Koi faltu field bheji to 400 aata he. Password ka qaida: kam se kam 10 harf, ek capital, ek small, ek number.

11. Tayyar JavaScript function (copy kar len)

Yeh function token khud lagata he, 401 par khud refresh karta he, aur refresh bhi fail ho to login par bhej deta he.

const BASE_URL = 'http://SERVER-ADDRESS:3000/api';
let refreshing = null;

async function api(path, options = {}) {
  const send = () => fetch(BASE_URL + path, {
    method: options.method || 'GET',
    headers: {
      'Content-Type': 'application/json',
      Authorization: 'Bearer ' + localStorage.getItem('accessToken'),
    },
    body: options.body ? JSON.stringify(options.body) : undefined,
  });

  let res = await send();
  if (res.status === 401 && localStorage.getItem('refreshToken')) {
    refreshing = refreshing || fetch(BASE_URL + '/v1/auth/refresh', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ refreshToken: localStorage.getItem('refreshToken') }),
    }).then(async (r) => {
      if (!r.ok) throw new Error('logged out');
      const t = await r.json();
      localStorage.setItem('accessToken', t.accessToken);
      localStorage.setItem('refreshToken', t.refreshToken);
    }).finally(() => { refreshing = null; });
    try { await refreshing; res = await send(); }
    catch { localStorage.clear(); window.location.href = '/login'; return; }
  }
  const data = res.status === 204 ? null : await res.json();
  if (!res.ok) throw data.error;   // { code, message, details }
  return data;
}

async function login(companyCode, email, password) {
  const res = await fetch(BASE_URL + '/v1/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ companyCode, email, password }),
  });
  const data = await res.json();
  if (!res.ok) throw data.error;
  localStorage.setItem('accessToken', data.accessToken);
  localStorage.setItem('refreshToken', data.refreshToken);
  return data;   // data.user.userType se dashboard, data.services se menu
}
